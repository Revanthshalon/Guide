# System Architecture Reference

A personal reference library of system architecture patterns — what they are, where they break in production, and how to handle it.

Each pattern lives in its own folder with a `README.md` covering:

- **Overview** — the core idea and when it's actually a good fit
- **Pitfalls** — concrete ways it breaks in production
- **Production Mitigations** — how to handle each pitfall
- **References** — links, books, talks worth revisiting
